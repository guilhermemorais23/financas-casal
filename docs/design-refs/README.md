# Referências de design (DESIGN.md)

Coleção de arquivos DESIGN.md de 70+ marcas (Airbnb, Apple, Wise, Revolut, Spotify…),
vinda do [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md),
o repositório por trás do [getdesign.md](https://getdesign.md). Licença MIT (ver `LICENSE`).

Cada arquivo descreve cor, tipografia, espaçamento, componentes e o raciocínio por trás
de cada escolha de uma marca. Eles ficam aqui só como referência: nenhum é seguido
automaticamente. Para adotar um estilo, copie o arquivo escolhido para `DESIGN.md` na
raiz do projeto e adapte ao app.
